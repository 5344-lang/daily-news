# DAILY NEWS

매일 아침 관심 키워드 뉴스, 최신 심리학 실험 리포트, 구독 블로그 글을 자동으로 수집·편집해 종이신문과 이북(E-ink) 감성으로 발행하는 개인 조간 신문 웹앱입니다.

---

## 주요 기능

### 1. 자동 뉴스 수집 및 원문·이미지 추출
- **관심사 기반 큐레이션**: 설정한 카테고리별 키워드와 제외 단어를 바탕으로 뉴스 후보를 수집하고, Gemini AI가 기사 선정 및 핵심 정리 한 줄(`핵심:`)을 작성합니다.
- **원문 및 이미지 확보**: Google News RSS 링크를 실제 언론사 URL로 변환해 기사 본문과 대표 이미지를 수집합니다.
- **차단·단문 자동 보완**: 특정 언론사 접근 제한(`403`)이나 본문 길이가 지나치게 짧은 경우, 공개 AMP 페이지를 우선 시도하고 필요 시 같은 주제의 다른 언론사 기사로 대체합니다.

### 2. 심리학 실험 리포트 & 구독 블로그 수록
- **최신 심리 실험 리포트**: 등록된 연구 피드(예: PsyPost)를 매일 순환하며 원문과 핵심 요약을 함께 수록합니다.
- **구독 블로그 아티클**: 네이버 블로그(아이디 또는 URL 입력 시 RSS 자동 변환) 등 구독 중인 블로그의 새 글 또는 안 읽은 글을 원문 그대로 담아줍니다.

### 3. 신문지 · 야간 · 이북(E-ink) 읽기 모드
- **3가지 화면 모드**: `신문지` / `야간` / `이북` 모드를 자유롭게 전환할 수 있습니다.
- **이북 모드 지원**: 화면 좌우 터치, 키보드 방향키(`←`/`→`), 페이지 바로 이동 모달을 지원합니다.
- **읽기 편의 기능**: 글자 크기 조절(`가-`/`가+`), 사진 표시 토글, 현재 위치 기반 실시간 날씨 및 상단 한 줄 문장(편집장 한줄평·명언·응원 등)을 제공합니다.

### 4. 취향 학습 & 스크랩 카드뉴스 메일
- **좋아요 / 싫어요**: 기사별 피드백을 기록해 다음 신문 발행 시 AI의 기사 선별 취향에 반영합니다.
- **보관함 & 메일 발송**: 마음에 드는 기사를 `저장`해 두면 다음 날 새벽 신문 발행 시 카드뉴스 형태 메일로 자동 발송되며, 보관함에서 즉시 발송도 가능합니다.
- **웹 UI 설정 연동**: GitHub Fine-grained 토큰을 브라우저에 등록하면 웹 화면의 `설정` 창에서 키워드·발행 시간·구독 목록을 수정하고 즉시 신문을 다시 발행할 수 있습니다.

## 기술 스택 및 구조

- **자동화 / 배포**: GitHub Actions, GitHub Pages
- **수집 / 편집**: Python (`scripts/generate_news.py`), Gemini API
- **메일 발송**: Python (`scripts/send_scrap_email.py`), `.github/workflows/send_scrap.yml`
- **프론트엔드**: Vanilla HTML / CSS / JavaScript (`index.html`, PWA `manifest.json`)

```text
daily-news/
├── .github/workflows/
│   ├── daily.yml               # 매일 정해진 시각 신문 자동 생성 및 배포
│   └── send_scrap.yml          # 스크랩 기사 카드뉴스 메일 발송
├── scripts/
│   ├── generate_news.py        # 뉴스·연구·블로그 수집, 원문 스크래핑, AI 편집
│   └── send_scrap_email.py     # 저장된 기사 메일 발송
├── data/
│   ├── today.json              # 최신 발행 신문 데이터
│   ├── preferences.json        # 좋아요/싫어요/스크랩 기록
│   └── images/                 # 수집된 기사 대표 이미지
├── config.json                 # 신문 이름, 키워드, 발행 시간, 구독 목록 설정
└── index.html                  # 신문 뷰어 및 설정 UI
